# Fact Checking System Frontend

Next.js web application for article submission, job progress, and fact-check reports. Product behavior is intentionally deferred until the backend contracts and the relevant frontend specification are approved.

## Stack

- Next.js with App Router
- React and TypeScript
- Tailwind CSS
- ESLint
- pnpm

## Local setup

```bash
pnpm install
pnpm dev
```

The app is available at `http://localhost:3000`.

## Quality checks

```bash
pnpm check
```

This runs ESLint, TypeScript validation, and a production build.
